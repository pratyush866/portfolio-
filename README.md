## ⚡ Deployment & Hosting

2. Select repository `portfolio-`.
3. Framework Preset: **Other** (Root directory: `./`).
4. Click **Deploy**.

### Option B: Local Browser
Simply open [`index.html`](./index.html) in any modern web browser.
